# MyLab Insight Backend

This Space hosts the FastAPI backend for the **MyLab Insight** project.

It exposes a REST API for:
- Interpreting common lab values
- Generating AI-style educational explanations
- Storing lab history
- Generating PDF reports

The app is implemented in `main.py` using FastAPI.
